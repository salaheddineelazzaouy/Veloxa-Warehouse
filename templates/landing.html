Immutable stock ledger

Every inbound, outbound, and adjustment is a permanent, signed movement. Current quantity is always derived via SUM() over the ledger — no stock field.

Back-order isolation

Deficit tracking runs in a separate bounded context. When inbound stock arrives, the system automatically fulfills open back-orders.

Audit trail + PII redaction

Every mutation and PII read is logged. Raw PII never reaches log files — automatic redaction built in.

Role-based access

Four built-in roles with granular permissions. Auditors can inspect every movement but never modify data.

Atomic transactions

All stock operations run inside @transaction.atomic with row locking. No over-selling, no race conditions.

API-first

Built with Django REST Framework + JWT. Rate limited at 100/h anonymous, 1,000/h authenticated. Full OpenAPI docs.

{% endfor %}

Architecture at a glance

Nginx WAF Django 5.1 PostgreSQL 16 + Redis 7

No raw SQL. No stock fields. Only immutable movements. — Zero-downtime migrations, blue-green deployment, modular monolith.
